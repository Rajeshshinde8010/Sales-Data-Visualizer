# Sales Data Visualizer

## Overview

Sales Data Visualizer is a data analytics and visualization project designed to analyze sales performance, identify business trends, and present actionable insights through interactive charts and dashboards.

This project helps businesses understand revenue patterns, customer behavior, product performance, and regional sales distribution using data visualization techniques.

---

## Project Objectives

* Analyze sales data effectively
* Visualize business performance metrics
* Identify trends and growth opportunities
* Generate meaningful business insights
* Improve decision-making using data visualization

---

## Features

* Interactive sales analysis
* Revenue and profit visualization
* Monthly and yearly trend analysis
* Product category performance tracking
* Regional sales comparison
* Data-driven business insights

---

## Dataset Information

The dataset includes business sales records with:

* Order Date
* Sales
* Profit
* Quantity
* Product Categories
* Customer Segments
* Region and State Information

The dataset is used for data cleaning, analysis, and visualization purposes.
